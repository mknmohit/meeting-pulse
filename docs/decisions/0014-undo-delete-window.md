# Delete confirmation uses a protected text entry

**Status:** PROPOSED
**Date:** 2026-08-08
**Supersedes:** -

## Context

Deleting status, viewer access, and recovery data cannot be undone.

## Decision

Require the owner to type `delete` in a confirmation sheet before the destructive action enables.

## Consequences

Accidental clicks are less likely, while deletion takes one deliberate extra step.
