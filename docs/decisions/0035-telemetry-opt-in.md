# Telemetry is opt-in

**Status:** PROPOSED
**Date:** 2026-08-08
**Supersedes:** -

## Context

The MVP is privacy-sensitive and does not need background analytics to answer its core question.

## Decision

Keep telemetry off by default and preserve an existing anonymous identity only when the owner opted in.

## Consequences

The default data boundary stays minimal and an opted-in owner does not lose continuity during migration.
