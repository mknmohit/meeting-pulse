# Station default size

**Status:** PROPOSED
**Date:** 2026-08-08
**Supersedes:** -

## Context

The Station needs room for a persistent 288pt mast column and a working detail pane.

## Decision

Open the split Station at 940 by 620 points, with the working surface allowed to grow to its minimum content size.

## Consequences

The initial window is predictable, while long copy and section forms can remain readable without clipping.
