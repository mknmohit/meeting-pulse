# Getting help

Use the right channel and you will get a faster answer.

## Bug or unexpected behaviour?

Open a [bug report](https://github.com/mknmohit/meeting-pulse/issues/new?template=bug.yml).
Include the surface (macOS app, viewer, Supabase, build, docs), reproduction
steps, expected vs actual, and a redacted diagnostics export if you have one.

Never paste pairing codes, recovery phrases, Supabase session tokens, or
meeting content into an issue or discussion.

## Feature or design idea?

Open a [feature request](https://github.com/mknmohit/meeting-pulse/issues/new?template=feature.yml).
State the primary user, the problem today, the proposed behaviour, which
privacy boundary applies, and the smallest complete change.

## Question, "how do I…", or design discussion?

Start a thread in [GitHub Discussions](https://github.com/mknmohit/meeting-pulse/discussions).

## Security or vulnerability?

Do not file a public issue. Follow [`SECURITY.md`](./SECURITY.md) and report
privately to the maintainers.

## What this repo is not

- Not a 24/7 support channel. Maintainers respond when they can.
- Not a place to ask for help configuring third-party Apple Developer
  accounts, Cloudflare Pages, or Supabase tenants you control — those are
  upstream configuration questions.
